## 使用
1.打开应用程序或使用解释器运行
2.在顶部的文件菜单中，导入您的我的世界纹理文件夹以及您的版本文件夹，系统通常会自动搜寻这些文件，如果找不到，请手动浏览并选择  
3.继续在文件菜单中找到浏览版本，挑选需要修改的版本，并选择下边列出的世界  
4.在地图中查看世界已经被保存区域的俯视图，您可以在顶部编辑菜单开启编辑侧边栏，在侧边栏中创建一条高速公路  
5.选中这条高速公路，然后在地图中自由绘制  
6.在一切完成之后，点击顶部文件菜单中的打印到世界，等待进度条加载完成  
>[!WARNING]
>尽管系统会在开始操作之前自动备份存档，但我们仍然强烈建议您在进行操作之前手动备份存档！
